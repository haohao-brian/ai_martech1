# 憲法修正案 (Constitutional Amendments)
*解決憲法級原則內部矛盾*

## 第一修正案：註釋與文檔

### 原始衝突
- MP037：註釋只能用於臨時/不確定代碼
- MP007：要求完整文檔組織
- P010：要求複雜邏輯必須有註釋

### 修正內容
將 MP037 重新詮釋為分層要求：

```yaml
MP037_改進版:
  生產代碼註釋規則:
    - 複雜業務邏輯：必須註釋（解釋"為什麼"）
    - 演算法實現：必須註釋（解釋"如何"）
    - 臨時代碼：標記 #TEMP 或 #TODO
    - 不確定代碼：標記 #UNCERTAIN 或 #REVIEW
    - 簡單明顯代碼：不需註釋（代碼即文檔）
  
  禁止的註釋:
    - 廢棄但未刪除的代碼（應直接刪除）
    - 描述"做什麼"的註釋（代碼本身應清楚）
    - 過時的註釋（誤導性）
```

## 第二修正案：演進與DRY平衡

### 原始衝突
- MP018 (DRY)：不要重複自己
- R058：演進優於替換，允許 v1, v2, v3 並存

### 修正內容
在 MP018 中加入"演進條款"：

```yaml
MP018_演進條款:
  原則：
    - 代碼不應重複
  
  合法例外（需標記）:
    1. 演進式開發:
       - 標記：#EVOLUTION: v1->v2
       - 期限：最多保留3個版本
       - 條件：生產環境穩定性需求
    
    2. A/B測試:
       - 標記：#ABTEST: feature_flag
       - 期限：測試結束後30天內清理
    
    3. 漸進式遷移:
       - 標記：#MIGRATION: old->new
       - 期限：所有用戶遷移完成後清理
```

## 第三修正案：調試模式特權

### 原始衝突
- MP017：關注點分離（憲法級）
- P015：調試時可違反分離原則

### 修正內容
建立"憲法緊急狀態"機制：

```yaml
調試模式憲法特權:
  觸發條件:
    - 生產環境重大故障
    - 關鍵功能開發受阻
    - 複雜問題診斷
  
  允許的違反:
    - 暫時合併關注點（MP017）
    - 暫時重複代碼（MP018）
    - 暫時違反模組化（MP016）
  
  必要措施:
    - 標記：#DEBUG_MODE: [issue_id]
    - 記錄：違反的原則和原因
    - 期限：問題解決後48小時內恢復
    - 審查：事後需技術審查
  
  不可違反（即使調試）:
    - MP002 (預設拒絕) - 安全性
    - MP029 (禁止假資料) - 資料完整性
    - MP082 (可重現性) - 科學性
```

## 第四修正案：語言原則統一

### 原始問題
- 多個NSQL相關原則（MP024, MP027, MP062等）
- 功能重疊，界限不清

### 修正內容
合併為單一憲法原則：

```yaml
MP024_統一自然查詢語言:
  核心語言:
    - Natural SQL (NSQL) - 主要查詢語言
    - R Statistical Query Language (RSQL) - 統計擴展
    - AI Meta Language (AIML) - AI通訊協議
  
  實現層級:
    - L1: 語法定義（憲法級）
    - L2: 語言實現（法律級）
    - L3: 方言變體（命令級）
    - L4: 使用慣例（規則級）
```

## 第五修正案：初始化生命週期

### 原始問題
- MP031 (初始化優先)
- MP033 (反初始化最後)
- MP039 (啟動時一次)
- MP048 (通用初始化)
- 概念重疊但規則分散

### 修正內容
統一為生命週期管理原則：

```yaml
MP031_統一生命週期管理:
  初始化階段:
    1. 系統初始化（一次性）
    2. 應用初始化（每次啟動）
    3. 模組初始化（按需）
    4. 函數初始化（每次調用）
  
  執行階段:
    - 正常執行
    - 錯誤處理
    - 狀態管理
  
  清理階段:
    1. 函數清理（返回前）
    2. 模組清理（卸載時）
    3. 應用清理（關閉時）
    4. 系統清理（最後執行）
```

## 實施指南

### 修正案生效程序
1. **提案期**：公開討論7天
2. **審議期**：技術委員會審查3天
3. **表決期**：需2/3開發者同意
4. **公告期**：通過後公告3天
5. **生效日**：公告期滿自動生效

### 過渡條款
- 既有代碼享有90天寬限期
- 提供自動化遷移工具
- 設立諮詢窗口協助調整

### 解釋權
- 憲法修正案解釋權屬於架構委員會
- 具體實施細節由技術主管決定
- 爭議案例提交技術委員會仲裁

## 修正案優先級

當多個修正案衝突時：
1. 後修正案優於前修正案
2. 特定修正案優於一般修正案
3. 安全相關修正案最優先

## 定期檢討

- 每季檢討修正案實施情況
- 每年評估是否需要新修正案
- 保持憲法的活力與適應性
